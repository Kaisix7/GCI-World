# Official Competition Rules and Compliance Guide

## Competition Context: GCI Global 2026 Home Credit Default Risk

The **GCI Global 2026 Competition** is an educational machine learning tournament centered on predicting customer loan repayment default using the **Home Credit Default Risk** dataset.

This document formally details the official competition constraints, integrity standards, data protection protocols, and citation requirements.

---

## 1. Permitted Data & External Data Prohibition
- **Strict Rule:** **No external data may be used at any stage of feature engineering or modeling.**
- The solution relies exclusively on the official provided files:
  - `input/train.csv` (171,202 loan applications)
  - `input/test.csv` (61,500 loan applications)
- External credit ratings, macroeconomic indices, alternative credit bureaus, or internet scraping are strictly forbidden.

---

## 2. Prohibition of Hand-Labeling
- **Strict Rule:** Manual labeling or rule-based assignment of test target probabilities is strictly prohibited.
- Modifying test predictions manually based on exploratory data analysis (e.g. setting risk to zero for specific sub-populations) violates tournament fairness.
- All submitted probabilities must be **automatically generated by a machine learning model or algorithmic ensemble** that generalizes across unseen data with similar characteristics.

---

## 3. Prevention of Target Leakage
- Any target encoding, mean response calculation, or out-of-fold imputation must be **strictly computed inside training partitions** of cross-validation.
- Outer validation folds and test partitions must never contribute labels or influence statistics computed during feature transformation.
- Preprocessing steps that compute statistics across folds (e.g. imputing missing values using the global dataset median) are restricted to prevent data leakage.

---

## 4. Evaluation Metric & Submission Format
- **Metric:** Area Under the Receiver Operating Characteristic Curve (**ROC-AUC**) on predicted continuous probabilities versus true binary outcomes.
- **Submission Requirements:**
  - File format: CSV file with exact headers: `SK_ID_CURR,TARGET`.
  - Exactly **61,500 rows** matching test IDs in sequential order (`171202` to `232701`).
  - No missing values (`NaN`), nulls, or infinities.
  - Predicted target values must lie strictly within the closed interval `[0.0, 1.0]`.

---

## 5. Ensuring Reproducibility
- In accordance with the assignment guidelines, all random number generation must be seeded across folds, data splitting, and model initializations.
- Top-ranking participants aiming for **Honors or Outstanding Student Recognition** must submit the reproducible code (`tutorial.ipynb` / `tutorial.zip`) capable of generating the exact submitted predictions.

---

## 6. Private Sharing & Attribution Guidelines
- In this tutorial tournament, collaboration and public discussion are permitted and encouraged to foster learning.
- **Citation of External Code:** Any referenced techniques, educational materials, or open-source libraries must be explicitly cited in the documentation to ensure clear academic attribution.
